# Cách chạy
- Chạy lệnh sau để tải thư viện
```bash
flutter pub get
```

- Sau đó tạo file .env 

```bash
API_URL= "http://mox.message.com"
```

- Cuối cùng chạy lệnh sau để chạy ứng dụng
```bash
flutter run 
```
